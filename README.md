# Toolbar

#### Description

This is a simple toolbar application.

#### Usage

Double click the **Toolbar.exe** file to start.

#### Shortcut List

The file **Shortcuts.txt** is a text file containing a list of shortcuts, which are added to the toolbar's combo box on startup.

The list can be edited in a text editor (e.g. Notepad).

When the list is updated, the application must be closed and restarted (double clicking **Toolbar.exe** while the application is running will close the application).
